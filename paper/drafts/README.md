# Paper drafts

Dated PDF snapshots of the paper at each milestone, so the journal can show how the paper developed.

| Draft | Date | What changed |
|---|---|---|
| [draft-2026-10-23.pdf](draft-2026-10-23.pdf) | 23/10/2026 | Final version: all sections complete |

**How to add a snapshot:** download the latest PDF from the Actions tab (see `paper/README.md`), save it here as `draft-YYYY-MM-DD.pdf`, add a row to the table above, update the "Latest draft" link in the main README, and commit with `report: paper draft YYYY-MM-DD`.
